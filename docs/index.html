    How the two codebases meet

    The base application above is IOF Resonance v1.0 running live: a 5D penteract (32 vertices, 80 edges) rotating through ten planes and projected down with a Möbius twist, while five jellyfish nodes — W, X, Y, Z, V — synchronise under Kuramoto coupling. The topographic module from the March 2026 integration is layered directly onto its real outputs: the jellyfish node positions serve as the mesh (MESH_POS), the terrain height field is built from each node's actual simulation error, and the climber's φ is the simulation's own Möbius phase, normalised to [0, 1]. Nothing in the topographic layer runs on placeholder signals.

    1. Topographic ascent first. Terrain peaks are detected on the canvas and recorded through the memory bank's normal record() path — same 10-state capacity and eviction as converged states. If a banked peak within Δφ ≤ 0.15 offers Q at least 20% above current, the reasoner climbs (confidence 0.92) and the simulation's Möbius phase animates to the summit.
    2. Predictive thermal shunting second. Smoothed per-node errors are projected 15 steps ahead; if any crosses the |error| 0.80 power wall while the fabric is unlocked, learning α shunts to 0.01 (confidence 0.98) before the breach arrives.
    3. Memory recall as the fallback. When coherence drops below 0.60, the instability pattern in the coherence trace picks the remedy: oscillation → harmonic lock, thermal drift → ensemble average of recent states, otherwise → best banked state, with confidence decaying as exp(−age / 500).
